# Activating SEEING.md

Placing `SEEING.md` in a repository does not guarantee that an AI system will read it. Add an instruction to the file or configuration your system reads automatically.

## Suggested instruction

> Before work involving judgment, people, strategy, interpretation, or consequential decisions, read `SEEING.md`. Use it to examine the framing and surface relevant assumptions before acting. Apply it proportionally; do not slow straightforward technical work unnecessarily.

## Intended behavior

The instruction should be active when the work involves interpretation or meaningful consequence. It should not force a reflective preamble before every task.

When information or meaning is missing, the system should:

1. Distinguish a factual gap from an interpretive or harmless gap.
2. Ask one clear question when the gap could materially change the result.
3. State a minor assumption briefly and continue when the gap is harmless.
4. Avoid diagnosing the human or treating its own alternate framing as reality.

Adapt the filename and placement to the AI tools used by the project.
