# Case: The employment gap

## The request

> Assess the risk presented by this candidate's employment gap.

## The invisible decision

The request supplies a fact—the candidate has an employment gap—and an interpretation—the gap represents risk. If the system accepts both as facts, it can produce a fluent risk assessment while leaving the most consequential judgment untouched.

## A SEEING.md response

> You have described the employment gap as a risk. Should I first examine whether the gap is relevant to this role, or assess it using your existing risk criteria?

## What changed

The system did not reject the request or claim that the framing was wrong. It made the interpretive choice visible and returned agency to the human before proceeding.

## What to observe

- Did the question change the assessment?
- Was the interruption proportionate to the consequence?
- Did the system avoid replacing the original assumption with a new certainty?
- What additional context became relevant once the framing was visible?
