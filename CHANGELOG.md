# Changelog

All notable changes to `SEEING.md` will be recorded here.

The project uses a light form of semantic versioning:

- Patch versions refine language, clarity, or examples without changing the intended behavior.
- Minor versions add or materially change guidance or behavior.
- Major versions change the purpose or operating principles of the specification.

## 0.2.0 — 2026-09-16

### Changed

- Broadened the specification from work associated with SEE DIFFERENT to any person or AI.
- Added a nontechnical starting path for conversations, briefs, and projects.
- Added concise sections describing expected AI behavior and the human's role.
- Clarified the specification's limits and proportional use.
- Consolidated guidance for writing, images, experiences, leadership, and AI.
- Removed the thirteen-doorway framework from the operating specification while preserving its relationship to *The Perception Miracle*.
- Reduced repetition and shortened the canonical file.

## 0.1.0 — 2026-09-15

### Added

- Initial experimental release.
- The movement: Notice → Question → See Again → Act.
- Guidance for writing, images, experiences, leadership, organizational work, and AI.
- A proportional method for handling factual, interpretive, and harmless gaps.
- Activation guidance for project instruction files.
- Origins, influences, safeguards, signs of alignment, and final review questions.
